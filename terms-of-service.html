# Lueri International website ## Files you still need to add to `assets/` This page references these images, which weren't included in the HTML you pasted: - assets/logo-mark.png (light-mode logo) - assets/logo-mark-dark.png (dark-mode logo) - assets/favicon-32.png - assets/favicon-512.png - assets/apple-touch-icon.png - assets/og-image.png (social share preview image) Drop your existing logo/icon files into the `assets` folder using those exact names, and the site will pick them up automatically. ## Also referenced but not included - `terms-of-service.html` — the footer and booking form link to this page. Create one (even a simple one) at the same folder level, or remove/redirect those links. ## Deploy to GitHub Pages (matches the URL already baked into the page: emwas254.github.io/lueri_international) 1. Create a new GitHub repo named `lueri_international` under your account (emwas254). 2. Upload `index.html` (and your `assets/` folder + `terms-of-service.html`) to the repo root. 3. Go to Settings → Pages → Source → select the `main` branch, root folder → Save. 4. Your site goes live at https://emwas254.github.io/lueri_international/ within a few minutes. ## Deploy elsewhere instead Any static host works the same way — just upload index.html + assets folder: - Netlify: drag-and-drop the folder onto app.netlify.com/drop - Vercel: `vercel` CLI or drag-and-drop via dashboard - Your own hosting/cPanel: upload via FTP into public_html
